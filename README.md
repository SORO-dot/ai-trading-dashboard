# SORO GOJO

Static GitHub Pages dashboard for educational/paper market analysis.

## Files
Keep these four files in the repository root:
- index.html
- app.js
- style.css
- README.md

## Data
- BTC: Binance public 15m candles.
- GOLD: XAUS public XAU/USD chart feed.
- The page marks the feed STALE when a request fails.

## Analysis
Adaptive rule-based scoring using higher-timeframe structure, 15m structure, CRT/liquidity sweeps, FVG/IFVG-style checks and candle-flow pressure. It is not a guarantee of results and does not place orders.

## GitHub Pages
Repository Settings -> Pages -> Deploy from a branch -> main -> / (root).
